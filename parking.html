Smart Parking system

2nd Hackathon project

2023

Project Overview

This is my 2nd hackathon project and i was the team lead for this project. In this project we had made an working demo model of smart parking system in shopping malls and theaters.

When people visit malls or theaters they are not sure whether they can get a parking slot, I order to solve this problem we had made an demo of parking setup and an website.

In this people can book their parking slots 15 minutes prior through an app or website and if they book that slot will not ba vacant and within the given time if they didnt reach the parking that slot will automatically turns vacant. slots vacant status can be found using the Ultrasonic or Motion sensor

Research Motivation

To overcome the parking problem and if there is no parking slots available they can plan any alternate place to visit

Objectives

  • Slot booking via app or website
  • Slot vacancy will be updated via IoT sensors

Methodology

The sensors placed in the parking slot will capture the vehicle movement and it will update the slot availability in website and if a person book that slot it will remain booked till a particular time if the person didnt come within the stipulated time that slot will be shown vacant again
