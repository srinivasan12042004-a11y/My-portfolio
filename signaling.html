Automatic Traffic signalling system

Computer Science and automation

2025

Project Overview

This is my UG dissertation project where I created an demo-model for automatic traffic signaling system in which each side of the lane turns green according to the density of the vehicles

If any ambulance approach the lane that side will be automatically turned green. I made this demo using IoT sensors and Arduino Board

Research Motivation

In Coimbatore the signalling system is not efficent, to overcome this probelem i had made this working model and i had identifed 13 hotspot places where this model can acutally be implemented

Objectives

  • Signalling system based on the density of the vehicles
  • Ambulance lane should automatically turned on green using RFID tag
  • providing smooth traffic controlling system

Methodology

I had deployed the signal like setup and placed the ultrasonic sensor for vehicle density detection and using Arduino Mega 3286 board i implemented the logic through Arduino IDE programing language
