E-Alert

1st Hackathon project

2023

Project Overview

This is my 1st hackathon project where we came up with an idea of E-Alert

Usually we dont kow how much units of current we are consuming. after 2 months of bill only we knew how much units of current we used. This can sometimes lead to overusage of current.

We came up with an idea to solve this. Currently we will get notifications in our phone for data usage like 50% or 90% of data is over, after seeing this we will carefully use our data. Same logic applies to this also in our EB meter we will fix our own units according to our need so if 50% of units is consumed that corresponding number associated with the EB meter will recive this alert messaage so they can use the remaining units carefully

Research Motivation

To solve the elecctricity usage problem and make people aware of their own elecctricity usage

Objectives

  • We can set the limit of units according to our needs
  • they will recive 2 alerts one alert after 50% of usage and another alert for 90% of usage

Methodology

We had used GSM module to send the message to the phone and we used Arduino UNO board and Arduino IDE program to write the logic

Tools & Technologies

Arduino IDE GSM protocol MQTT protocol
